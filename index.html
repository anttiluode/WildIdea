What W2 actually tested

A 64-site damped wave ring had one hidden high-damping region at one of eight candidate addresses. A probe injected the same local pulse every time and reduced the short ring-down to one scalar receipt:

receipt = log(late local energy / early local energy)

All active policies used the same learned Gaussian response table and the same three-write budget.

The only important difference was where the next probe went.

What survived the tests

Scheduled probing survived

W1's first confusion matrix had a suspicious class-order asymmetry. W1b randomized the starting probe phase, balanced it within class, changed the observer map five times, and the active margin stayed near twenty points.

schedule artifact attacked

Probe choice itself mattered

W2's adaptive policy produced 13 distinct three-probe sequences. The second and third address depended on the earlier receipt. It beat the strongest fixed three-probe design selected from the same learned response model.

state → next action

What this is not

It is not evidence that consciousness is a scout, that brains use this exact mechanism, or that active sensing is new. W2 is squarely in Bayesian experimental-design / system-identification territory.

Also, W2 deliberately resets the low-energy field before each probe trial. That makes the adaptive-choice result clean, but it means we have not yet tested the stronger surfing picture in which every probe changes one continuously evolving medium that later probes inherit.

The next honest question: W3

persistent medium z(t)
      ↑        ↓
   write     local read

      tiny controller

          └── chooses next probe from current consequence

Can a tiny controller keep a changing field informative without resetting it, while beating fixed and random probing under the same action and compute budget?

That would be closer to the original "surfing" intuition. It should be tested as engineering first.
