## The new compile/runtime boundary

W4b suggests a stronger synthesis:

```text
stationary response law
+ stationary query costs
+ stationary nuisance distribution
        |
        v
OFFLINE COMPILER
choose a strong fixed experiment plan
        |
        v
runtime adaptivity may earn nothing
```

A WildIdea/PivotPoint-style runtime earns its existence only when the best query is genuinely **state contingent** in a way that cannot be compiled once:

```text
medium changes online
previous interventions alter inherited state
work/signals remain in flight
query cost or availability changes
nuisance regime changes
new alternatives become plausible
an action changes what future measurements are even possible
```

This is the strongest bridge to PivotPoint currently available:

> **A pivot is not valuable because it can choose. It is valuable when the current live state makes yesterday's compiled choice stale.**

That is an engineering boundary, not a consciousness claim.

## What would legitimately reopen WildIdea

Do not open W4c on another authored stationary ring.

A new gate should use an **external** task where adaptivity has structural reason to matter. At least one of these must be real rather than simulated for convenience:

1. **real query cost** — another measurement costs wall-clock time, energy, money, or intervention risk;
2. **nonstationarity** — the response law changes after the offline plan is compiled;
3. **persistent action effects** — the query changes the state inherited by later queries;
4. **external nuisance** — nuisance comes from somebody else's instrument/data;
5. **changing action set** — some queries become unavailable or newly useful as state evolves.

The strong baseline should be an offline/periodically recompiled design, not random probing.

A useful future question is therefore not

> does adaptive probing beat fixed probing?

but

> **when does runtime state contain enough decision-relevant information that re-querying online beats the best schedule compiled from past data, after charging both for their measurements and recomputation?**

If no suitable external task is found, stop. The synthetic ladder already did its job.
